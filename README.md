# 工作时间博饼

一个基于 Python 3.13 的桌面小程序，将**工作计时**与**闽南博饼**结合：工作积累博饼机会，掷骰获得自己设置的时间奖励或物品奖励。

## 使用说明

程序使用 Python 标准库和 Tkinter 图形界面，无需额外安装第三方 Python 包。

### Windows

1. 安装 [Python 3.13](https://www.python.org/downloads/)。
2. 下载 `博饼_工作计时版.pyw`，放入一个方便保存的文件夹。
3. 双击文件打开程序。若没有关联到 Python，可以在文件所在目录打开终端，运行：

   ```powershell
   py -3.13 "博饼_工作计时版.pyw"
   ```

Python 安装及文件关联的操作参见 [Python 官方 Windows 说明](https://docs.python.org/3.13/using/windows.html)。

如果不想在桌面看到数据文件，可以把程序放在单独的文件夹中，再为程序创建桌面快捷方式。程序已针对 Windows 高 DPI 显示做了适配，支持高分辨率屏幕。

### macOS

将文件扩展名从 `.pyw` 改为 `.py`，再使用 Python 3.13 运行，例如：

```bash
python3.13 "博饼_工作计时版.py"
```

运行环境需要支持 Tkinter；Python 官方的 macOS 安装包包含 Tk。也可以使用随安装包提供的 Python Launcher 打开 `.py` 文件，具体操作见 [Python 官方 macOS 说明](https://docs.python.org/3.13/using/mac.html)。

### 数据保存与退出

程序会自动在自身所在文件夹中生成数据文件。**更新程序时请保留这些文件；删除数据文件可能导致设置和记录丢失。**

| 文件 | 内容 |
| --- | --- |
| `bobing_data.json` | 奖品设置、库存、奖励余额、博饼记录、工作兑换统计及活动数据 |
| `bobing_current_session.json` | 工作计时会话备份 |
| `bobing_tasks.json` | 自定义任务列表；主存档中也保存任务配置 |
| `activity_records_日期_时间.ics` | 退出时导出的日历文件 |

移动或备份程序时，建议先正常退出，再复制整个文件夹。只把程序复制到一个**空文件夹**，会使用默认设置；同时复制数据文件，则会保留相应进度。

点击窗口右上角的 **× 会最小化窗口，计时继续运行**。需要真正退出时，请点击程序中的 **“导出日历保存数据并退出”**。程序关闭期间不会扣除时间奖励。

## 创意说明

工作计时负责记录时间，博饼负责增加一点期待感。把两者放在一起，就可以让每一段工作逐渐积累成一次掷骰机会，再把中奖结果兑换成自己喜欢的奖励。

奖励可以是“看电视两分钟”“玩游戏五分钟”，也可以是一块饼干或其他物品。内容、时长和库存都由自己设置，让休闲与奖励有具体的额度，也让重复的日常工作多一点趣味。

本程序采用适合个人使用的博饼奖励玩法：中奖后立即增加奖励余额。具体判定以程序内“规则与说明”为准。

## 功能说明

### 计时功能

#### 选择和编辑任务

- 点击任务按钮开始计时；切换任务会结束上一段活动，并开始新的活动。
- 新数据目录默认只有“工作”和“休闲”两个任务。“清空当前活动”会结束当前活动，不会删除已有记录。
- 点击 **“编辑任务列表”**，可以新增、删除、修改和调整任务顺序。
- 每个任务可以设置界面名称、日历名称、是否属于工作，以及是否导出到日历。
- 界面名称可以使用中文，日历名称可以保留原来的英文或专有名称。导出时使用设置的日历名称。

任务列表保存在数据文件中，可以按自己的需要修改。只有勾选为工作的任务才计入博饼机会。

#### 编辑、拆分和补记事件

工作计时页显示已记录的事件，可以修改任务及起止时间，也可以拆分事件、将事件恢复为未分配时间。同一个事件可以多次调整。

例如离席三小时原先全部记录为“休闲”，之后可以拆成两段，分别改为两小时“运动”和一小时“杂务”。相应任务可以先在任务列表中添加。

事件之间没有记录的时间会自动显示为 **“未分配时间”**，双击即可创建活动。未分配时间不会计入工作时长，也不会导出到日历。

也可以使用“快速修正所选事件的最后几分钟”，把所选事件末尾的一段时间改为其他任务；没有选中事件时，修正当前活动。

#### 合并事件

使用 Ctrl 或 Shift 选择多个事件，再点击 **“合并所选事件”**：

- 时间连续且属于同一个任务：直接合并。
- 时间连续但任务不同：选择合并后的任务。
- 时间不相邻，或中间有未选中的事件、未分配时间：提示错误，不执行合并。

调整活动记录后，相关工作时长和博饼机会会同步重新计算。

#### 导出日历

点击 **“导出日历保存数据并退出”** 后，程序会结束当前活动、保存数据，并按退出时间生成 `.ics` 日历文件。可将文件导入支持该格式的日历软件。

**退出时只保留最后一个实际活动，其余活动按各任务的导出设置写入日历，然后从活动列表中移除。** 短于五分钟的活动也会导出。未分配时间不导出；关闭导出选项的任务不会写入日历，但仍按上述规则清理。

最后一个活动留待下次导出。如果当前只有一个活动，本次日历中不会包含它。下一次打开程序时，该活动结束到当前时间之间会显示为未分配时间，可以自行补记。累计工作兑换统计和博饼机会会保留。

### 工作兑换博饼机会

默认每工作 **25 分钟**获得一次博饼机会。可以在“工作兑换博饼机会”区域修改分钟数，点击 **“保存工作兑换设置”** 生效。

- 只累计标记为工作的活动，休闲和未分配时间不计入。
- 未满一次兑换所需时长的零散工作时间，以及尚未使用的机会，会跨会话保留。
- 可以在顶部手动添加博饼次数。
- 每次有效掷骰使用一次机会，未中奖或奖品库存不足也会扣除；无效输入不扣次数，一次掷骰获得多个奖项也只扣一次。

修改兑换分钟数或调整工作事件后，程序会重新计算应得次数。如果减少的机会已经用掉，会显示待补回次数；之后的工作或手动添加会先补回欠额，已经获得的奖励不会追回。

该区域的 **“重设”** 按钮会清零累计兑换工作时长、手动增加次数、累计使用次数和欠额。从点击重设的时刻开始重新累计，旧活动不会重新兑换机会。兑换分钟设置、活动记录、奖品和正在进行的计时都会保留。

### 博饼功能

#### 掷骰与判定

进入“博饼与奖励”页面，可以选择：

- **随机掷骰并领奖**：自动生成六个 1～6 的整数，立即判定并发奖。
- **手动输入**：在一个输入框中输入六个数字，例如 `412355`，点击 **“判定并领奖”** 或按回车。也支持空格、逗号分隔。

数字顺序不影响结果。手动输入过程中不会自动领奖；需要有可用博饼机会才能进行有效掷骰。

#### 奖品设置

“奖品设置”页面中的每个奖项有三个输入框：

| 输入项 | 含义 |
| --- | --- |
| 奖品内容 | 自定义奖励名称，例如“看电视”或“饼干” |
| 每次奖励分钟 | 正整数表示时间奖励；**0 表示物品奖励** |
| 初始份数 | 本局最多可发放的奖励份数 |

每中奖一份，库存减少一份，同时增加对应奖励。库存份数与奖励分钟是不同的数量。

例如，一秀设置为 **“看电视 / 2 / 32”**，博到两次后库存剩 30 份，看电视余额增加 4 分钟；设置为 **“饼干 / 0 / 32”**，则增加 2 件饼干。

同名、同类型奖励会自动累加；同名的时间奖励和物品奖励分别统计。修改奖励名称或类型只影响之后的发奖，已经获得的余额会保留。

#### 奖项与规则

| 奖项 | 基本判定 | 默认初始库存 |
| --- | --- | ---: |
| 状元 | 四个或五个四点、五颗非四点同点，或六颗同点 | 1 |
| 对堂 | 一到六点各一个 | 2 |
| 三红 | 三个四点 | 4 |
| 四进 | 四颗非四点的骰子同点 | 8 |
| 二举 | 两个四点 | 16 |
| 一秀 | 一个四点 | 32 |
| 插金花 | 下述四种特殊组合的额外奖励 | 1 |
| 安慰奖 | 未匹配其他奖项时发放，需先启用 | 999 |

程序优先判定六同、状元和对堂，再判定其他奖项。因此，对堂中的四点不会另外获得一秀。

以下四种组合，除了状元奖励，还会额外获得一份 **“插金花”** 奖项的奖励，四种组合共用这一库存：

- 插金花：四个四点、两个一点。
- 六勃红：六个四点。
- 遍地锦：六个一点。
- 六勃黑：六个相同的二、三、五或六点。

状元和插金花分别扣库存，一项库存不足不会影响另一项发奖。插金花不会额外发放对堂奖励。

在奖品设置中还可以调整以下选项，修改后需要保存：

- **四进带一秀 / 二举、五子带一秀**：默认开启，可自行关闭。
- **启用安慰奖**：默认关闭。开启后，没有符合其他奖项的组合会获得一份安慰奖。已经博中奖项但该奖项库存不足时，不会改发安慰奖。
- **允许超出库存领奖**：默认关闭。开启后，库存为 0 或负数仍会发奖，例如一秀库存为 0，再中奖后变为 -1。关闭后保留已有负库存，但库存不大于 0 的奖项停止发奖。

“博饼记录”页面可以查看掷骰时间、骰子结果、奖项和实际发奖情况。

### 奖励领取与倒计时

在“博饼与奖励”页面的 **“03 我的奖励”** 中，列表只显示剩余奖励，不展示累计获得或已领取总数。

#### 直接领取

“直接领取”列表同时包含物品奖励和时间奖励。选择奖励，填写本次领取数量，再点击 **“已领取奖励”**：

- 物品奖励：领取一件，扣除一件。
- 时间奖励：**领取一件等于扣除一分钟**，无需再启动倒计时。

这种方式适合登记已经拿走的物品或已经自行使用的奖励时间。领取时不会再次扣减奖品库存，也不能超过剩余余额。

#### 时间倒计时

进入“时间倒计时”，选择奖励并填写本次使用分钟数，再点击 **“开始使用”**。也可以点击 **“用完所选奖励”**，使用该奖励的全部剩余时间，包括不足一分钟的余额。

倒计时按实际经过的时间扣减奖励，支持暂停、继续和结束使用。暂停或提前结束后，未使用的余额保留；倒计时结束会弹出提示。正常退出会暂停奖励倒计时，下次打开后可以继续，程序关闭期间不扣时间。

### 重设与重新开始

两个按钮作用不同，均不会清空已获得的时间或物品奖励：

| 按钮 | 重置内容 | 保留内容 |
| --- | --- | --- |
| 工作兑换区的“重设” | 兑换工作时长、手动增加次数、累计使用次数、次数欠额 | 兑换分钟设置、活动记录、奖品、博饼记录、当前计时 |
| “重新开始博饼” | 本局库存恢复为设定的初始份数，清空骰子结果和博饼记录 | 奖品与规则设置、已获得奖励、工作计时、兑换统计、博饼机会、奖励倒计时 |

重新开始博饼后，之前获得的奖励仍然可以使用。程序不提供专门清空奖励的按钮；需要扣减余额时，可以按份数直接领取，或使用时间倒计时。
